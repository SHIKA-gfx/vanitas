# 003. 픽업 배너 ★3 풀 108의 의문 해소

- 날짜: 2026-09-19
- 상태: 해소

## 상황

2026-09-16, 무츠키(드레스) 픽업 모집의 확률 공시에서 풀 크기를 수집했다.
공시에는 개별 학생 확률만 나오므로, 그룹 확률에서 역산해 통상 ★3 풀을 108명으로 구했다.


## 문제

108이 무엇을 뜻하는지 확정할 수 없었다. 두 가지 해석이 가능했다.

1. 전체 ★3 풀에서 **픽업 학생 1명만** 빠진 수
2. 동시 진행 중인 **특별(한정) 픽업 대상까지** 빠진 수

2번이라면 108은 그 시점에만 유효한 값이다. 계산기가 이를 고정값으로 쓰면
다른 배너에서 틀린 확률을 내놓게 된다.

## 조치

값을 버리거나 추측으로 확정하지 않고, **불확실하다는 사실을 데이터에 기록**했다.

```json
"concurrentLimitedBannerUnverified": true,
"note": "이 배너에 특별 픽업이 동시 진행되었는지 미확인.
        108이 순수 통상만의 수치일 가능성이 있다."
```

## 해소

2026-09-19, 상시 모집 공시(`/probability/7799`)를 수집했다.
상시 모집의 ★3 풀은 **109명**이었다.
